Report

Introduction

This portfolio website was developed as part of my learning process in web development. The goal was to create a personal website to showcase my projects and skills. I used HTML and CSS to build the site, focusing on creating a clean and responsive design. This report will discuss my learning experience, design decisions, challenges faced, and validation process.

Learning Experience

During this project, I learned how to use HTML and CSS to build a website. At the beginning, I found it difficult to understand layout and grid systems. However, after practice, I became more confident using CSS Grid and Flexbox. I also learned how to debug problems, such as fixing layout issues and incorrect class names. One challenge I faced was making the website responsive, especially creating a hamburger menu for mobile view..Throughout this project, I gained valuable experience in web development, particularly in creating responsive designs and implementing consistent styling across multiple pages.

Design Decisions

One of the key design decisions I made was to use a dark-themed interface with contrasting accent colours. I chose colours such as dark blue and grey for the background, with a cyan accent colour to highlight important elements like links and buttons. This was inspired by modern portfolio websites that focus on minimalism and readability. I also used a background image with an overlay in the hero section to create a visually appealing introduction. In terms of technical implementation, I used CSS Grid for layout design and Flexbox for navigation alignment. I also implemented hover effects and transitions to improve user interaction, such as lifting project cards and changing link colours. One of the most important aspects of this project was making the website responsive. I achieved this using media queries and a hamburger menu system that appears on smaller screens. This ensures that the website is usable on both desktop and mobile devices. .

Challenges Faced

One of the main challenges was aligning elements correctly using CSS. I also had issues with responsive design where elements were not displaying properly on mobile devices. Another issue was getting hover effects to work correctly due to class name mistakes. I fixed these problems by checking my code and testing different solutions.

Validation

The website was validated using the W3C Markup Validator and CSS Validator to ensure it meets web standards and is free of errors.
